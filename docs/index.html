How do I get my editor key? (one time)
  1. Go to GitHub → Fine-grained tokens (sign in as the repo owner).
  2. Token name: WBIT admin. Expiration: your choice.
  3. Resource owner: your account. Repository access: Only select repositories → wbit-app-config.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it, paste above.

Keep this key private — anyone with it can edit the station content.
